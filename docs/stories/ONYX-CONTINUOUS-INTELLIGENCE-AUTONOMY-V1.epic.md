# Epic ONYX-CONTINUOUS-INTELLIGENCE-AUTONOMY-V1

**Status:** Release Candidate  
**Owner:** Cyryx Labs  
**Architecture lead:** Vega (`@architect`)  
**Product lead:** Janus (`@pm`)
**Source successor:** Onyx `1.1.25` / Release Workflow V90

## Goal

Turn Onyx into a continuously improving, company-capable agentic assistant through three bounded sprints, while preserving the accepted desktop/mobile humanoid and every existing authority, privacy, release and provider boundary.

## Immutable boundaries

- No primary HUD, humanoid, palette, voice, motion or layout change belongs to this epic.
- Learning cannot create authority, grant permissions, weaken approvals or execute remembered instructions.
- Raw conversations are not long-term training data by default. Only typed, minimal candidates with provenance may persist.
- AEXOS is integrated as a Cyryx-owned, version-pinned orchestration boundary; it is not copied ad hoc into the Onyx runtime.
- The external knowledge-product repository is a behavioral reference only. No source, protected expression, branding, notice or restricted implementation is imported.
- Away work remains bounded by explicit mission scope, tool/domain allowlists, deadlines, cost ceilings, checkpoints, receipts, kill switch and reconciliation.
- An 80% gross-margin objective is a configurable decision guardrail, never an invented outcome. Missing or unverified revenue/cost inputs produce `unknown`, not a favorable estimate.
- Web opportunities remain cited candidates and cannot independently trigger outreach, purchase, publication or account mutation.

## Stories

1. `ONYX-CL-01-CONTINUOUS-LEARNING-ONBOARDING-V1` — governed conversation learning, rapid post-install interview, owner controls and initial hybrid retrieval.
2. `ONYX-CL-02-AEXOS-DEPARTMENTAL-AUTONOMY-V1` — pinned AEXOS adapter, department routing, governed Away Mode plans and economic envelopes.
3. `ONYX-CL-03-OPPORTUNITY-INTELLIGENCE-ECONOMICS-V1` — cited live research, opportunity queue, verified economics and promotion/evaluation gates.

## Epic exit

- All three story suites and canonical Onyx regressions pass.
- Visual freeze evidence proves no unauthorized visual source changed.
- A successor release is packaged and installed; source, package, installed, physical-device, OAuth/account and live-provider evidence remain separately reported.
- Export, revoke, forget, kill and rollback paths are demonstrated.

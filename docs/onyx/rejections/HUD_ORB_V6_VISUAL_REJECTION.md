# HUD / Orb V6 visual decision

HUD/Orb V6 remains an accepted technical and runtime anchor, but its visual
composition is rejected as the target Onyx experience. Its symmetric side
rails, rectangular information groupings and shallow Orb presence read as a
dashboard rather than a cinematic holographic entity.

V6 manifests and acceptance evidence remain immutable. V7 is an additive,
default-off visual successor and rolls back to the exact installed V6 host.

## V7 Candidate 001 disposition

V7 Candidate 001 is also visually rejected before E6 and was never live. Its
full-bleed shell was directionally correct, but its center read as a sparse
vector radar with a glowing point rather than a volumetric particle entity.
Candidate 002 preserves the shell and replaces that center with a large,
masked, texture-dense neural sphere.

## V7 Candidate 002 disposition

V7 Candidate 002 was approved as a visual baseline and remained default-off,
but was superseded before E6 by an explicit owner request to remove the
decorative orbital tracks outside the neural sphere. It was never live.
Candidate 003 preserves the approved sphere, halo, core, internal neural mesh,
shell and command keel while removing only those external arcs.

# Phase 7 Founder Command V1 checkpoint

## Scope

This candidate implements the next ordered Phase 7 slice over the accepted
Approved Sources + Company Graph V1 root. It supplies deterministic daily and
weekly executive projections, operational freshness, structured conflict
detection and evidence-linked prioritization. It remains exactly default-off.

## Implemented contract

- daily Founder Brief and weekly operating review cadence;
- cited portfolio, blocker, dependency, proposed-decision and risk views;
- known/inferred/unknown claim separation;
- explicit per-semantic current/aging/stale windows and refresh deadlines;
- declared contradiction preservation and potential incompatible-status
  detection without silent overwrite;
- source-grounded revenue-opportunity queue with explicit abstention when
  absent;
- top three actions ranked by impact, urgency, graph confidence, effort and
  downside;
- known context, inference, unknowns, alternatives, verification, completion
  evidence and downside for every proposed action;
- authenticated “what changed since last brief” delta;
- complete brief digest and internal-reference validation;
- zero persistence, URL fetch, artifact-content read, model, network, process,
  provider, browser, execution, UI, dashboard or live-runtime call.

## Proportional regression result

Eight fresh Python processes reproduced:

- 168 passed tests;
- 65 passed subtests;
- 0 failed;
- 0 errors;
- 8 explained platform skips.

The skips are limited to Windows absence of POSIX mode/FIFO/link-count/
quarantine/restart contracts. Windows-specific paths in those suites passed.

## Limits

This candidate is not live-wired and does not schedule or display a brief.
It detects declared contradictions and structured incompatible status
conflicts; general open-text/NLP contradiction discovery is not implemented.
Action/opportunity candidates must be supplied by a later governed intake
path. Phase 7 is not exited and the full Onyx PRD is incomplete.

E6 remains pending until an independent acceptance envelope rehashes this
candidate and reproduces the selection.

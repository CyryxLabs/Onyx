# Capability delta — Phase 8 Microsoft Graph Read V1

## Added behind one exact default-off flag

- Microsoft Graph global v1.0 calendar-view read.
- Normalized calendar and unread-mail daily brief with account/workspace
  identity and deterministic digest.
- Bounded mail metadata search and individually scoped message-body read.
- Local immutable calendar and email drafts with no mutation authority.
- Credential-alias, scope, rotation and revocation re-attestation.
- Exact-origin and exact-route provider paging.

## Not added

- OAuth registration, device login, refresh-token handling or live HTTP.
- Provider-side drafts.
- Calendar create/update/cancel, external invitations or shared-calendar
  changes.
- Mail send/reply/forward/update/delete.
- Task, notification, Drive, OneDrive or Office connectors.
- Startup, voice, V13, dashboard or UI wiring.
- Phase 8 exit or full PRD completion.

# Argos V1 checkpoint

First Argos slice: a default-off, deterministic, hermetic world-signal
registry — the 100% proprietary Cyryx world-intelligence foundation
(successor to the dropped third-party World Monitor, from which nothing is
copied). It adds one module, one feature flag and no runtime wiring.

`core/argos_v1.py` (`ONYX_ARGOS_V1`) is entry-bound to the accepted Phase 9
exit four-file acceptance tuple. It builds rights-noted `ArgosSourceV1`
records (closed kinds: market_data/official/press/social) and categorized
`WorldSignalV1` records (closed 8-category taxonomy; registered source
required; injected integer observed_at; severity/confidence 1–5) into a
sealed snapshot with deterministic projections (`signals_for`, bounded
`brief`, weight desc / id asc). `is_actionable()` is structurally False —
Argos informs, it never acts. The module calls no model, opens no network,
spawns no process, persists nothing and takes no action.

The cumulative selection reproduces 868 passing tests and 96 passing
subtests across thirty-three fresh Python processes — the thirty-two files
of the Phase 10 audience-strategy selection plus this slice's thirty-five
adversarial tests — with seventeen platform-specific skips and zero
failure/error.

Scope and limits: registry and briefs only. No live fetching (the
owner-gated Phase 9 live-ingestion connector remains the only later path to
real network), no provider adapters, no scheduling, no action surface, no
startup/voice/UI/dashboard wiring, and no claim that the full Onyx PRD is
complete.
